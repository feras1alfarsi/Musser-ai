## 📌 Overview

**مُيسّر (Muyassar)** is a modern Arabic RTL landing page for an AI-powered document intelligence SaaS product. The platform helps legal teams, financial services, and enterprise professionals extract key insights, risks, and obligations from complex documents — in seconds.

---

## ✨ Features Showcased

| Feature | Description |
|---|---|
| ⚠️ **Risk Detection** | Automatically flags hidden risks and ambiguous clauses in contracts |
| 📝 **Smart Summarization** | Condenses 100-page reports into key bullet points |
| 📋 **Obligation Extraction** | Identifies who owes what and when |
| 🔍 **Semantic Search** | Natural language Q&A across your entire document library |
| 📊 **Comparative Analysis** | Side-by-side version comparison to spot differences |
| 🔒 **Enterprise Security** | SOC 2 compliant, end-to-end encrypted |

## 🚀 Getting Started

This is a **static website** — no build tools or dependencies required.

### Run Locally

```bash
# Clone the repository
git clone https://github.com/your-username/muyassar.git

# Navigate into the project
cd muyassar

# Open in your browser
open index.html
```

Or simply drag `index.html` into any browser.

### Live Server (recommended for development)

If you use VS Code, install the **Live Server** extension and click *Go Live* for hot-reloading.

## 🎨 Design Highlights

- **Full RTL support** (`dir="rtl"`, `lang="ar"`) for native Arabic reading experience
- **Dark navy theme** with gold (`#D4A853`) and teal (`#2DD4BF`) accent colors
- **Animated SVG neural core** in the hero section
- **Canvas-based particle system** background
- **Scroll-reveal animations** on all sections
- **Animated number counters** (98% accuracy, 50x faster)
- **Fully responsive** — mobile hamburger menu included

## 🔧 Customization

| What to change | Where |
|---|---|
| Brand name & colors | `styles.css` → CSS variables at `:root` |
| Hero text & CTAs | `index.html` → `.hero` section |
| Pricing plans | `index.html` → `.pricing` section |
| Particle behavior | `script.js` → particles config |
| Chatbot integration | `index.html` → Botpress `<script>` tags at bottom |
